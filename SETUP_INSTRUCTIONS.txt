PDX UNDERGROUND ENVIRONMENT SETUP INSTRUCTIONS
===============================================

These instructions will help you set up the basic environment structure for PDX Underground.
Follow these steps in order if you're experiencing issues with the regular setup process.

STEP 1: ENSURE SCRIPTS ARE COMPILED
-----------------------------------
1. Open Unity and wait for script compilation to complete
2. Check the Console for any compilation errors
3. Fix any errors before proceeding

STEP 2: VALIDATE THE SETUP SCENE
--------------------------------
1. In Unity, go to: PDX Underground > Validate Setup Scene
   - If this menu item doesn't appear, proceed to Step 3
2. The validator will:
   - Check if the setup scene exists
   - Create it if needed
   - Ensure it has the required EnvironmentSetup GameObject
   - Add the SetupEnvironment component if missing

STEP 3: MANUAL SETUP (IF NEEDED)
--------------------------------
If Unity menus aren't working, follow these manual steps:

1. Open the SetupScene:
   - Double-click Assets/Scenes/SetupScene.unity in Project window
   - If it doesn't exist, create a new scene and save it with this name

2. Add the EnvironmentSetup GameObject:
   - Right-click in Hierarchy > Create Empty
   - Rename to "EnvironmentSetup"

3. Add the SetupEnvironment component:
   - Select the EnvironmentSetup GameObject
   - In Inspector, click Add Component
   - Type "SetupEnvironment" and select it

4. Save the scene:
   - File > Save or Ctrl+S (Cmd+S on Mac)

STEP 4: RUN THE SETUP
---------------------
1. With the SetupScene open, press the Play button
2. Watch the Console for progress messages
3. When complete, exit Play mode
4. Check Logs/setup_log.txt for detailed output

STEP 5: VERIFY RESULTS
----------------------
1. In Project window, check that these folders were created:
   - Assets/Materials/Environment/Streets, Tunnels, Speakeasy
   - Assets/Textures/Environment/Streets, Tunnels, Speakeasy
   - Assets/Models/Environment/Streets, Tunnels, Lighting
   - Assets/Prefabs/Environment/Streets/Compositions, Props

2. If folders are missing:
   - Check for errors in Logs/setup_log.txt
   - Ensure Unity has write permissions to the project directory
   - Try running the setup again

STEP 6: NEXT STEPS
------------------
After successful folder setup:
1. Use the Environment Setup Wizard to generate textures and materials
2. Create prefabs for environment elements
3. Set up your game scenes using the created assets

If you continue to experience issues, refer to the README.md file for additional troubleshooting tips.
